FAQ

Good questions.

Is it safe to use?

F1zz Tweaks only changes settings that Windows already has. It saves the original value before each change and can restore it. Tweaks that affect the whole PC are marked ADMIN, and you can create a Windows restore point from inside the app first. Still, tweaking always carries some risk, so read what each tweak does.

Will Windows or my antivirus warn me?

Possibly. Apps from small publishers often show a Windows SmartScreen "unknown publisher" warning, and some security tools are cautious about programs that change system settings. Only download F1zz Tweaks from this website. If you're unsure, create a restore point first.

Do I need to run it as administrator?

Many tweaks work without it. Tweaks that change settings for the whole PC are marked ADMIN and need the app to be run as administrator.

What happens when my Premium ends?

When a Premium license expires, is refunded, or is removed, the app tells you and then restores the Premium tweaks it applied back to your original settings. Your free tweaks and your own settings are not touched.

Can I use my code on another PC?

Each code is locked to one PC. If you replace your PC, open a ticket in our Discord and we'll help you move it.

Does it work on Windows 10 and 11?

Yes. A few tweaks only apply to Windows 11 and say so in their description.

What information do you collect?

The app itself has no accounts and collects no email. The checkout provider shares your order details with us (such as the name and email you gave at checkout) so we can verify your purchase, and in a Discord ticket we see your Discord name and your Device ID so we can make your code. We never see your card details. Read the full privacy section.

Can I get a refund?

See our refund policy. If something doesn't work for you, open a ticket and tell us what happened.
