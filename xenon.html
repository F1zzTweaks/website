Questions

Does it show over Fortnite and other fullscreen games?

Yes when the game runs in Windowed Fullscreen or Borderless, which is what most players use. In Fortnite: Settings → Display → Window Mode → Windowed Fullscreen. Exclusive fullscreen hides every overlay (Windows draws the game straight to the screen). Xenon tells you when a game is in that mode.

Will it get me banned?

Xenon never touches the game. It's a separate see-through window: it doesn't read or change game memory and doesn't inject anything. Some competitive games and tournaments have their own rules about crosshair overlays, so check them before you play ranked.

Inside F1zz Tweaks or standalone, which should I pick?

Both need F1zz Tweaks Premium on your PC. Take the F1zz Tweaks version if you like controlling everything from F1zz Tweaks; take the standalone if you want a separate app with its own window and tray icon.

Windows warned me about the file. Is that normal?

New apps from small publishers often get a SmartScreen "unknown publisher" warning. Only download Xenon from this page.
